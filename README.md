# 🎸 コードトーン・トレーナー

ギターのコードトーンを視覚化・クイズ形式で徹底トレーニングできる無料Webツール。

## 機能

- 👁️ **見える化モード** — クロマチック円・指板図・5ステップロードマップ
- 🎯 **クイズモード** — 単体コード / コード進行文脈での出題。苦手コードを自動優先出題
- 🎸 **コード進行モード** — II-V-I等の実戦進行で共通音を確認

## 開発

\`\`\`bash
npm install
npm run dev
\`\`\`

## デプロイ

mainブランチへのpushで GitHub Pages へ自動デプロイされます。
